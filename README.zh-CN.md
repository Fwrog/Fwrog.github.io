## 研究方向

我目前的兴趣可以概括为：如何把空间数据、视觉感知和可复现计算结合起来，服务于更可靠的城市与环境分析。

主页叙事主要收束到三条线：

- **城市感知 / 地理空间 AI**：街景影像、移动 GIS、城市分析、空间数据科学和智慧交通。
- **面向建成环境的计算机视觉 / RGB-D**：RealSense 标定、深度-彩色对齐、三维重建和基础设施检测工作流。
- **遥感 / 环境建模 / 可复现空间计算**：Google Earth Engine、生态指标、GPP 反演和可审查、可复跑的空间计算流程。

更完整的研究作品集见：**[fwrog.github.io/zh](https://fwrog.github.io/zh/)**。

## 代表项目

### GEE Agent Skill：计划优先的 Earth Engine 工作流

<img src="./images/projects/gee-agent-workflow.jpg" alt="GEE agent workflow preview" width="720">

面向 Google Earth Engine 的 agent-native 命令行 harness。它把自然语言空间分析请求转成可审查计划、可验证脚本、安全 preflight、显式确认导出和可复现 trace。

**关键词：** Python, Google Earth Engine, CLI, Jinja2, reproducibility

**仓库：** [Fwrog/gee-agent-skill](https://github.com/Fwrog/gee-agent-skill)

### RealSense Calibration Tools

<img src="./images/projects/realsense-charuco.png" alt="RealSense ChArUco calibration target" width="360">

面向 Intel RealSense D435i 的轻量标定工具包：打印 ChArUco/ArUco/checkerboard 靶标、导出出厂参数、OpenCV 彩色相机标定、RGB-D 对齐 QC 和 HTML 报告生成。

**关键词：** Python, OpenCV, RealSense SDK, RGB-D, calibration

**仓库：** [Fwrog/realsense_calibration_tools](https://github.com/Fwrog/realsense_calibration_tools)

### 成都市高分辨率 GPP 反演

<img src="./images/projects/gpp-inversion.png" alt="GPP inversion map preview" width="720">

本科毕业论文相关工作：连接 HLS v2.0 影像、FLUXNET 观测、Google Earth Engine、Python/MATLAB 处理和机器学习实验，用于细尺度 GPP 制图。

**关键词：** HLS v2.0, FLUXNET, GEE, LSTM/SVM, urban ecology

**状态：** 论文与结果已有；公开代码包装仍在整理中
