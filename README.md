## Research Direction

I am interested in how spatial data, visual sensing, and reproducible computation can support more reliable urban and environmental analysis.

My current portfolio is organized around three connected directions:

- **Urban Sensing / Geospatial AI**: street-view imagery, mobile GIS, urban analytics, spatial data science, and smart transport.
- **Computer Vision / RGB-D for the Built Environment**: RealSense calibration, RGB-D alignment, 3D reconstruction, and infrastructure inspection workflows.
- **Remote Sensing / Environmental Modeling / Reproducible Workflow**: Google Earth Engine, ecological indicators, GPP inversion, and reviewable spatial-computation pipelines.

For the fuller research portfolio, see my website: **[fwrog.github.io](https://fwrog.github.io/)**.

## Featured Projects

### GEE Agent Skill: plan-first Earth Engine workflows

<img src="./images/projects/gee-agent-workflow.jpg" alt="GEE agent workflow preview" width="720">

An agent-native command-line harness for Google Earth Engine workflows. It turns natural-language geospatial requests into reviewable plans, validated Earth Engine scripts, safe preflight checks, confirmed exports, and reproducible traces.

**Keywords:** Python, Google Earth Engine, CLI, Jinja2, reproducibility

**Repository:** [Fwrog/gee-agent-skill](https://github.com/Fwrog/gee-agent-skill)

### RealSense Calibration Tools

<img src="./images/projects/realsense-charuco.png" alt="RealSense ChArUco calibration target" width="360">

A lightweight toolkit for Intel RealSense D435i calibration workflows: printable ChArUco/ArUco/checkerboard targets, factory-parameter export, OpenCV color-camera calibration, RGB-D alignment QC, and HTML report generation.

**Keywords:** Python, OpenCV, RealSense SDK, RGB-D, calibration

**Repository:** [Fwrog/realsense_calibration_tools](https://github.com/Fwrog/realsense_calibration_tools)

### High-Resolution GPP Inversion for Chengdu

<img src="./images/projects/gpp-inversion.png" alt="GPP inversion map preview" width="720">

Undergraduate thesis workflow connecting HLS v2.0 imagery, FLUXNET observations, Google Earth Engine, Python/MATLAB processing, and machine-learning experiments for fine-scale GPP mapping.

**Keywords:** HLS v2.0, FLUXNET, GEE, LSTM/SVM, urban ecology

**Status:** thesis artifact; public code packaging pending
